# jogoMario
Este é um projeto acadêmico que replica o jogo do Mario com HTML, CSS e JavaScript, baseado no vídeo original do YouTube listado abaixo.
Vídeo original do projeto
[Como criar um jogo SIMPLES usando HTML, CSS e JavaScript](https://www.youtube.com/watch?v=r9buAwVBDhA&t=1s)
Requisitos para rodar o projeto
- Navegador moderno (Chrome, Firefox, Edge)
- Nenhuma instalação extra é necessária
- Basta abrir o arquivo `index.html` no navegador
Aviso de direitos autorais
Este projeto foi desenvolvido **apenas para fins acadêmicos**, com base no vídeo acima. Todos os créditos do conteúdo original pertencem ao autor do vídeo. O código foi adaptado exclusivamente para aprendizado.
